# 📌 Sobre o Projeto

O Nexus Smart Home é um projeto acadêmico de desenvolvimento de uma residência inteligente em escala reduzida, integrando conceitos de Engenharia Civil, eletrônica e automação residencial. O projeto tem como objetivo demonstrar a aplicação de tecnologias inteligentes em ambientes residenciais, proporcionando maior praticidade, conforto, eficiência energética e modernização das edificações. A proposta consiste na construção de uma residência utilizando estrutura em MDF, incorporando um sistema de iluminação inteligente por meio de uma fita LED endereçável WS2812, controlada por uma placa Arduino UNO.



# 🎯 Objetivos

- Desenvolver um protótipo de residência inteligente.

- Integrar conceitos construtivos e tecnológicos.
  
- Implementar um sistema de iluminação RGB endereçável.
  
- Desenvolver efeitos luminosos programáveis.
  
- Explorar a utilização de microcontroladores na automação residencial.
  
- Aplicar conceitos de inovação e tecnologia na construção civil.

# 💡 Sistema de Iluminação Inteligente

Um dos principais recursos do Nexus Smart Home é o sistema de iluminação RGB, desenvolvido com fita LED WS2812. Diferentemente das fitas RGB convencionais, a WS2812 permite o controle individual dos LEDs, possibilitando a criação de diferentes efeitos luminosos, combinações de cores e animações programáveis. O gerenciamento do sistema é realizado por meio da placa Arduino UNO, responsável pelo processamento dos comandos e controle dos efeitos de iluminação. Para proporcionar melhor distribuição visual da luz, é utilizado acetato branco translúcido como elemento difusor, permitindo a criação de efeitos luminosos nas paredes internas da residência.



# 🏗️ Desenvolvimento Construtivo

A estrutura física da residência é desenvolvida em MDF, permitindo a montagem de um protótipo arquitetônico em escala reduzida.

O processo construtivo contempla:
  
- Planejamento e desenvolvimento do modelo residencial.
  
- Preparação e montagem das peças em MDF.
  
- Adaptação dos elementos internos para instalação elétrica.
  
- Instalação da fita LED WS2812.
  
- Desenvolvimento do circuito eletrônico utilizando Arduino UNO.
  
- Programação dos efeitos de iluminação.
  
- Testes de funcionamento e integração dos componentes.



# 🔌 Arquitetura do Projeto

O projeto é dividido em três principais áreas:

**Estrutura física:** desenvolvimento e montagem da residência em MDF.

**Sistema eletrônico:** integração do Arduino UNO com a fita LED WS2812.

**Automação residencial:** programação e gerenciamento dos efeitos luminosos.



# 🚀 Resultados Esperados

O Nexus Smart Home busca demonstrar como a integração entre engenharia, eletrônica e tecnologia pode contribuir para o desenvolvimento de residências mais modernas e funcionais. O protótipo apresenta uma aplicação prática da automação residencial, utilizando iluminação RGB endereçável para demonstrar possibilidades de personalização, controle e modernização dos ambientes.
